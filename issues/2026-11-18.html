LLM training · RL · arXiv cs.AI · Nov 17
ReST-RL: Unified Reinforced Self-Training for Policy-Value LLMs
A unified framework that trains both the policy (what to output) and value (how good is this output) components of an LLM together via reinforced self-training, without separate reward models. Shows improved reasoning chain quality on math and code benchmarks with less reward hacking than standard RLHF variants. Note: arXiv API unreachable this run; paper data via web search aggregates.
arXiv cs.AI — Nov 17 →
LLM agents · Memory · arXiv cs.AI · Nov 11
Don't Just Trust Your Memory: Evidence-Linked Memory for LLM Agents
LLM agents that use retrieved memories without grounding them in source evidence tend to hallucinate or misattribute recalled facts. This paper proposes evidence-linked memory — memories that carry explicit provenance pointers to their source observations — reducing memory-induced degradation on long-horizon agent tasks. Code is linked in the paper.
arXiv cs.AI — Nov 11 →
LLM agents · Interpretability · Faithfulness
Adversarial Faithfulness Auditing for LLM Agent Reasoning Traces
Chain-of-thought reasoning traces can look plausible while having no causal relationship to the model's actual outputs. This paper introduces adversarial faithfulness auditing: a framework that deliberately constructs counterfactual CoT traces and measures whether the model's outputs change as they should if the reasoning were genuine. Practical implication: traces that pass this audit are meaningfully more trustworthy.
arXiv — Adversarial Faithfulness Auditing →
LLM training · Self-improvement · Multi-step
Chain-of-Verification for Autonomous LLM Self-Correction
A self-correction approach where the LLM generates a chain of verification questions about its own output, answers them, and then revises based on its own verification results. Unlike approaches that require an external verifier, this is entirely self-contained. Shows consistent improvement across factual QA and reasoning benchmarks with no additional training data.
