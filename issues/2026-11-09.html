View on GitHub →
Stars

Platform
iOS/macOS/ARM
Method
Binary translation
Highlights
  • Not emulation — recompilation

    Game code is statically translated to native ARM instructions before run time — faster than interpret-and-execute emulation and no JIT needed on iOS.

  • Bypasses iOS JIT wall

    iOS bans runtime code generation (JIT) except in special entitlements. Ahead-of-time translation sidesteps this limit cleanly.

  • ARM convergence

    Switch (ARM Cortex-A57), iPhone (Apple Silicon, ARM), Mac (Apple Silicon, ARM) — the ISA alignment is what makes this viable at all.

So what?

Static binary translation is a clever technical exploit of the ARM convergence between Nintendo Switch and Apple devices. Whether it ships as a consumer product or stays research is an open question, but the technique is real and the ARM convergence is permanent.

arXiv:2610.31494 · October 2026 · benchmark
AgentVQA: A Unified Benchmark for Agentic Visual Understanding
1,000 challenging real-world agentic examples across 5 domains: web agents, robotics, egocentric video, games, and spatial planning — 23 source datasets. The first benchmark evaluating VLMs on the full breadth of agentic visual tasks. Web-agent performance correlates poorly with robotics performance.
arxiv.org/abs/2610.31494 →
arXiv:2609.03493 · September 2026 · tool use
Making Every Tool Call Count: Necessary Tool-Evidence Path Rewards
Reinforcement learning reward shaping that makes agentic VLMs more selective about when to call tools. Key finding: performance gains come from better tool call targeting, not more tool calls. Suggests current agent evals that reward more tool use are optimizing the wrong thing.
arxiv.org/abs/2609.03493 →
arXiv:2608.17889 · August 2026 · agents · RAG
VisDocAgentBench: Benchmarking Agents for Visually Rich Document Retrieval
Closed-corpus benchmark for agentic retrieval from documents with charts, tables, and infographics — the category static RAG fails on. Key finding: iterative search and page inspection matter more than retrieval model choice. Points toward agent loops for enterprise document AI.
arxiv.org/abs/2608.17889 →
arXiv:2607.19336 · July 2026 · deployment
Agents in the Wild: Where Research Meets Deployment
Survey of real-world LLM agent deployments vs. lab benchmarks: agents perform significantly worse in production than on evals, with tool-call latency and cascading errors as the top failure modes. Calls for deployment-conditioned benchmarks. The gap between lab and prod is the key unresolved problem in agent engineering.
arxiv.org/abs/2607.19336 →
