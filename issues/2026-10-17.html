CONTEXT COMPRESSION · prompt middleware

Context compression middleware that shrinks tool output before it hits the LLM — without losing the signal.

Why it's trending

headroom sits between your agent's tool calls and the LLM context window. It compresses verbose tool outputs — stack traces, grep results, file listings, API responses — down to the semantically dense core, reducing prompt size without losing the information the agent actually needs. ~75k stars (Oct 12 tracker). The problem it solves: long tool outputs are one of the fastest ways to exhaust your context window, and most of it is noise.

Highlights
  • Compresses before the LLM sees it

    headroom intercepts tool call results and strips low-information content (boilerplate, whitespace, repeated tokens) before they're injected into the context window.

  • Configurable compression targets

    Stack traces, file diffs, search results, API JSON — each compression strategy is configurable and pluggable. The defaults handle the common cases out of the box.

Context window exhaustion is one of the top pain points in production agent deployments. headroom addresses it at the source — tool output — rather than at the expensive end (buying more context). Worth benchmarking against your own pipelines: the signal-preservation quality at high compression ratios is where it will either earn its place or not.

arXiv · 2610.19433 · Oct 14benchmarking
EvoProbe: Evaluation-Driven Benchmark Evolution for LLM Agents

Addresses benchmark saturation and data contamination in static LLM agent evals by proposing evaluation-driven benchmark evolution — the benchmark grows and adapts as agents get better at it. Tackles the "GPT-N-solved SWE-bench" problem at its root rather than patching it with larger splits.

Read →
arXiv · 2610.20099 · Oct 14evaluation
EvalBuilder: Can LLMs Build Efficient Benchmarks?

Tests whether LLM agents can autonomously construct benchmarks that preserve the statistical conclusions of expensive reference evaluations — essentially, "can the model build its own test suite?" Early results suggest yes, with caveats around adversarial self-evaluation. The implications for automated eval pipelines are significant.

Read →
arXiv · 2610.00372 · cs.AIagent reliability
When Harnesses Lose the Signal: Causal Evaluation of Recovery in LLM Agents

Examines what happens when evaluation harnesses (the scaffolding that runs agents through tasks) introduce causal noise that contaminates recovery signals. Relevant to anyone interpreting SWE-bench or similar results — the harness is not a neutral observer, and this paper quantifies how much that matters.
