Persistent cross-session memory for Claude Code — every project context survives restarts.

Why it's trending

109k stars, +14.2k this week — the week's top mover on GitHub Trending. claude-mem is a TypeScript extension that hooks Claude Code's session lifecycle to persist every conversation, decision, and code context to a local SQLite store. When you reopen a project, Claude is immediately up to speed: previous decisions, open TODOs, and architectural choices are injected back as context. The surge followed a viral demo showing zero-context-loss across 47 consecutive daily coding sessions on a single codebase.

arXiv cs.LG · 2026-10-30 · 847 upvotes
LLM Debate Reduces Overconfidence in Algorithmic Trading

The paper behind TradingAgents' star surge (see #02). Researchers show that pitting two LLMs with opposing mandates (Bull vs. Bear) against each other before a trading decision reduces the overconfidence that causes single-agent systems to over-size positions. The key finding: debate helps most on ambiguous signals; on clear signals, it adds latency with no benefit. Practical implication: use debate selectively, not on every tick. arXiv →

arXiv cs.CL · 2026-10-29 · 621 upvotes
MEMLONG: Persistent Episodic Memory for Long-Horizon Agents

A systematic study of episodic memory architectures for agents that must operate over days or weeks. Compares flat retrieval, hierarchical summarisation, and graph-structured memory. Key finding: hierarchical summarisation outperforms pure vector retrieval on tasks requiring temporal reasoning ("what did the user decide about X last Tuesday?"). The code is released under Apache-2.0 and complements projects like claude-mem (#01 above). arXiv → · Code →

Proposes a lightweight 7M-parameter router that classifies each incoming query and routes it to the cheapest model that can handle it correctly.
