05010203040506HMFPLDBZWTWP NotRexed/Hookshot
SummaryGitHub
Game Compatibility · C++ · Native Recompilation

Zelda: Ocarina of Time — natively recompiled for Nintendo Switch 2.

Why it's trending

2.1k stars. Hookshot targets the Nintendo Switch 2 Remake of The Legend of Zelda: Ocarina of Time, applying native recompilation — the technique popularised by N64Recomp — to the NS2 version. Native recompilation statically lifts the original binary's MIPS instructions to C, which is then compiled natively for the target platform. The result runs at native speed without an interpreter loop — unlike an emulator. This is a performance-first approach for a specific, well-loved title. Created November 5. Source: GitHub Search API.

  • Native recompilation vs emulation

    Statically lifts binary instructions to C and compiles natively — runs at hardware speed rather than through an interpreter. Fundamentally different from Lichii (#01).

  • Specific title, specific purpose

    Targets one game, not a general emulator. Narrow scope means higher chance of being correct and complete — this is engineering, not ambition.

So what?

Native recompilation is the technique that will likely produce the first playable, high-performance ports of Switch-era games on PC. Hookshot is early but it's the right approach — unlike emulation, the ceiling for native recomp is native hardware performance.

PAPER · Native Recompilation · Cross-referenced: Hookshot (#05)
N64Recomp: Statically Recompiling N64 Games into Native Code

The technique behind Hookshot (#05) was formalised in the N64Recomp project by Mr-Wiseguy, which produced a fully playable PC port of Zelda: Majora's Mask in 2024. The core method: static binary translation of MIPS instructions to C, compiled with any native compiler targeting the host platform. No formal arXiv paper — the technical writeup lives in the project README and issue threads. The approach is well-understood; Hookshot's contribution is applying it to NS2 hardware. Source: N64Recomp GitHub (verified); Hookshot README (not independently verified this run).
