0101020304050607080910HMFPLDBZWTWP deepseek-ai/dsh-superagent-prototype
SummaryGitHub
Agents · Autonomous · TypeScript · MIT

DeepSeek's prototype for a fully autonomous agent system — persistent planning across sessions.

Why it's trending

19.7k stars, new this week. dsh-superagent-prototype is DeepSeek's research prototype for a next-generation autonomous agent. Unlike chain-of-thought wrappers, it implements a full planning-and-execution loop: the agent decomposes a goal into a persistent task graph, executes sub-tasks in parallel, checks results against an internal critic, and re-plans if any branch fails. Memory is scoped per-project and survives restarts. MCP-compatible tooling lets it call external services as first-class actions. The repo launched alongside a brief paper draft ("Towards a More Autonomous Agent System") that circulated widely.

Highlights
  • Persistent task graph

    Goals decompose into a durable task graph that survives session restarts — the agent picks up exactly where it left off.

  • Parallel sub-task dispatch

    Independent branches of the task graph execute concurrently, reducing wall-clock time for multi-step goals.

  • Internal critic loop

    Each completed sub-task is evaluated against the original goal; failures trigger automatic re-planning rather than silent hallucination.

  • MCP-compatible tooling

    External services (file I/O, web search, code execution) are exposed as MCP tools — first-class actions, not hacks.

  • Project-scoped memory

    Conversation and decision history are namespaced per project; no cross-contamination between unrelated tasks.

So what?

DeepSeek releasing a prototype rather than a polished product is notable — this is research infrastructure, not a consumer tool. The architectural pattern (persistent task graph + critic loop) is the same one Anthropic uses internally for Claude Code's parallel agent dispatch, now open-source.

agent-autoloop — set a task, walk away. Background agentic execution loop for the CLI.

Why it's trending

3.4k stars, new this week. agent-autoloop is a TypeScript CLI wrapper that runs an agent task in a persistent background process, monitors its output, and re-triggers if it stalls or errors. Think of it as a process supervisor for agentic workflows: you define the task, set a success condition, and let it loop until done. It hooks Claude Code's session events and surfaces a compact status dashboard in the terminal. The pattern of leaving an agent running overnight and reviewing results the next morning has taken off, and autoloop is the cleanest tool for it so far.

agent-spec — An OpenAPI-inspired YAML format for declaring LLM agent capabilities, tool permissions, memory scopes, and escalation policies. Write the spec once; the companion TypeScript runtime enforces it at execution time. Addresses the "agent ran further than intended" problem that dominated HN threads this week.

ink-flow — A markdown-first creative writing editor that keeps AI suggestions strictly inline and opt-in — no sidebar, no chat panel. Each suggestion appears as a dismissible ghost-text overlay. Designed as the antidote to the kind of LLM-generated slop that heydamir/unslop (#03) is built to detect. Pairs naturally with unslop as a write → check pipeline.
