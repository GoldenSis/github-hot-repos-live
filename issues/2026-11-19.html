Test-time compute · Inference · arXiv 2611.23202 · Nov 18
ATI: Adaptive Test-time Inference for Efficient LLM Reasoning
Most test-time compute work (chain-of-thought scaling, repeated sampling) spends the same compute budget on every query regardless of difficulty. ATI proposes an adaptive budget controller that allocates more reasoning steps to hard queries and fewer to easy ones, achieving the same benchmark scores at 30–45% lower average compute. Practical implication: significantly cheaper inference for mixed-difficulty production workloads. Note: arXiv API unreachable this run; paper data via web search aggregates. Cited as arXiv 2611.23202.

Ambient LLMs: Passively Useful AI for Low-Attention Contexts
Ambient LLMs investigates a new interaction model: LLMs that run continuously in the background, monitoring context and surfacing observations without being explicitly prompted. Rather than a chat model waiting for a turn, an Ambient LLM watches your work and flags when something needs attention. The paper evaluates ambient agents on coding assistance and document analysis. Long context · Persistent memory · arXiv 2611.23228 · Nov 18
Spool: Persistent Conversation Context Beyond the Context Window
Spool addresses the fundamental limitation of fixed-length context windows in long-running assistant sessions. It maintains a compressed "spool" of past conversation that the LLM can retrieve and re-read as needed, rather than simply truncating old turns. The spool stores semantic summaries rather than raw tokens, enabling conversations that span months without quality degradation. Cited as arXiv 2611.23228.
